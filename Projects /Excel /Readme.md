# Coffee Sales Dashboard – Guided Excel Project

## 📌 Project Overview
This project is part of my **Data Analytics Journey**, where I am practicing and enhancing my skills through guided projects.  
The focus of this project was to build a structured and professional **Excel Dashboard** to analyze coffee sales data.

## 🎯 Objectives
- Learn and apply advanced Excel functions
- Clean and format raw data for analysis
- Create pivot tables and slicers for dynamic reporting
- Build interactive dashboards with clear visualizations

## 🛠️ Skills Practiced
### Excel Functions
- **XLOOKUP**
- **INDEX-MATCH combination**

### Data Formatting
- Modifying column names
- Removing blanks and filling corresponding data
- Text formatting
- Formatting as Table

### Pivot Tables & Slicers
- Creating custom fields
- Adding time frames
- Building custom slicers

### Visualizations
- Line charts for sales trends
- Bar charts for country-wise sales
- Customer performance dashboards
- Interactive filters for better presentation

## 📊 Dashboard Features
- **Total Sales Over Time** (line chart by coffee type)
- **Sales by Country** (bar chart)
- **Top 5 Customers** (bar chart)
- **Dynamic Filters**: Order Date, Roast Type, Size, Loyalty Card

## 📂 Repository Contents
- `coffeeAnalysis.xlsx` – Coffee product dataset

  * orders

  * PivotTable
  * Country
  * Sales

  * Dashboard
